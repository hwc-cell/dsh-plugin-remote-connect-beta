# 用共享出口（relay）：不改域名、不配服务器

这条路的用法只有一句话：**出口由别人跑，你只装插件。**

## 你需要两样东西

1. **出口地址** —— 一个 `https://` 基址。**不填就是用官方出口**：`https://relay.dsh.lycheeledger.cn`，由项目作者托管。
   别人（朋友、或你自己搭的）给了你出口，就把那个地址填上，两条路只在"填不填地址"这一点上不同。
2. **邀请码** —— 一次性的，用过即废。这个只能从发你邀请的人手里拿。

官方出口是**默认值**，写在本仓库里（`lib/core/officialExit.js`）—— 它是**公开的产品端点**（性质同 ngrok.com），
不是私有值。用非官方出口时，地址只会出现在对方发给你的消息里。

## 怎么用

### A. 写进插件配置（面板 + 常驻）

```yaml
public:
  enabled: true
  tunnel: relay
  relay:
    url: https://relay.dsh.lycheeledger.cn   # 留空 = 官方出口；也可填别人给你的地址
    invite: <一次性邀请码>
    name: <你想要的子域名字，可留空>
```

第一次启动会拿邀请码去出口换回「**你的名字 + 一把访问口令**」：口令**先写进本地状态文件，再显示**（绝不显示还没落盘的值）。之后邀请码就作废了 —— 把它从配置里删掉即可，插件会复用已存的凭据，不会重复注册。

### B. 一条命令（不装 DSH 也能用）

```bash
npx dsh-plugin-remote-connect-beta serve --relay --invite <邀请码> --name <名字>   # 官方出口
npx dsh-plugin-remote-connect-beta serve --relay <出口地址> --invite <邀请码> --name <名字>
```

## 拿到之后是什么样

入口形如 `https://<名字>.<出口域名>/?k=<口令>`。面板里能看到**出口地址、你的名字、完整链接（可复制）和二维码**，把链接发给别人即可 —— 对方用浏览器打开就行，不改域名、不注册账号、不装客户端。

## 换口令 / 不用了

- 面板点「**换一个新口令**」→ 这一下是在**出口**上换（口令的权威在出口，你本机不生成它）。旧链接、旧二维码、已登录的浏览器立刻全部失效。
- 不想用了：停掉插件，并让出口提供方 `--revoke <你的名字>`。被吊销后出口会在一个巡检周期内切断你那条在线隧道，不只是挡住新连接。

## 必须知道的风险（一句话）

**走共享出口 = 把"运行 Harness 的这台机器"交给出口管理员。** 请求和响应都是明文经过出口，它**看得到，也改得了**；访问口令是出口签发的（它只在签发那一刻见过明文，落盘只存指纹），所以你必须信任跑出口的那个人或那台机器。

不放心就走**自带服务器**那条路（[`self-host.zh.md`](self-host.zh.md)）：服务器、域名、证书全是你自己的，中间没有第三方。两条路的逐项对照见 [README 的「出口是谁、谁看得见什么」](../README.zh.md)。
